# Micro-Gallery Lodging Template

เว็บไซต์ตัวอย่างสำหรับนำเสนอที่พักขนาดเล็ก พร้อมตัวเลือกแสดงผล 2 รูปแบบในหน้าเดียว:

- **Baan Suan Lodge** — ที่พักบรรยากาศธรรมชาติ เหมาะกับการพักผ่อนแบบสโลว์ไลฟ์
- **City Inn Minimal** — ที่พักสไตล์มินิมอลใจกลางเมือง

ผู้เข้าชมสลับตัวอย่างได้จากแถบด้านบนของหน้า แต่ละรูปแบบจะแสดงรายละเอียดที่พัก ห้องพัก ราคาเริ่มต้น สิ่งอำนวยความสะดวก แกลเลอรี ที่ตั้ง และช่องทางติดต่อ เว็บไซต์นี้เป็นหน้าแสดงข้อมูลเท่านั้น **ไม่มีระบบจองหรือชำระเงินออนไลน์** การสอบถามและจองทำผ่านโทรศัพท์หรือ LINE

> ข้อมูลชื่อที่พัก ราคา ที่อยู่ เบอร์โทร และ LINE ในโปรเจกต์เป็นข้อมูลตัวอย่าง ควรเปลี่ยนเป็นข้อมูลจริงก่อนเผยแพร่

## เริ่มต้นใช้งาน

ต้องติดตั้ง Node.js และ npm หรือ pnpm ก่อน

```bash
npm install
npm run dev
```

เปิด URL ที่ Vite แสดงในเทอร์มินัลเพื่อดูเว็บไซต์ในเบราว์เซอร์

## คำสั่งที่ใช้ได้

| คำสั่ง | รายละเอียด |
| --- | --- |
| `npm run dev` | เริ่มเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm run typecheck` | ตรวจสอบ TypeScript |
| `npm run build` | ตรวจ TypeScript และสร้างไฟล์สำหรับเผยแพร่ใน `dist/` |
| `npm run preview` | เปิดดูผลลัพธ์จาก build ในเครื่อง |

หากใช้ pnpm ให้ใช้คำสั่งที่ตรงกัน เช่น `pnpm install` และ `pnpm run dev`

## เทคโนโลยี

- Vite
- TypeScript
- Tailwind CSS v4

## โครงสร้างโปรเจกต์

```text
.
├── index.html           # โครงสร้างหน้าเว็บ
├── src/
│   ├── main.ts          # ข้อมูลที่พักและการแสดงผล/สลับธีม
│   └── style.css        # ธีมและสไตล์เพิ่มเติม
├── image/               # รูปภาพที่เก็บไว้ในโปรเจกต์
├── _html/               # ไฟล์ HTML ประกอบในโปรเจกต์
├── package.json         # สคริปต์และ dependencies
└── vite.config.ts       # การตั้งค่า Vite และ Tailwind CSS
```

## แก้ไขข้อมูลที่พัก

ข้อมูลของทั้งสองรูปแบบอยู่ใน `templatesData` ภายใน `src/main.ts`. ปรับข้อมูลตามต้องการ เช่น:

- `name`, `tagline`, `about` — ชื่อและคำแนะนำที่พัก
- `rooms` — ประเภทห้อง รายละเอียด สิ่งอำนวยความสะดวก และราคา
- `facilities` และ `gallery` — รายการบริการและภาพประกอบ
- `location` — ที่อยู่ เส้นทาง และลิงก์ Google Maps
- `contact` — เบอร์โทร LINE ID และลิงก์ LINE

รูปภาพภายใน `image/` ถูกอ้างอิงจากโค้ดโดยตรง ส่วนรูปภาพบางรายการของตัวอย่าง City Inn Minimal ใช้ URL จาก Unsplash จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดภาพเหล่านั้น
